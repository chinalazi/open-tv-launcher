# OpenTV Launcher

专为 Android TV 与机顶盒设计的纯本地、离线、开源电视启动器，内置儿童防沉迷观看时长管理与 PIN 码锁屏机制。

---

## 🌟 核心特性

1. **纯离线与零网络**：
   - 清单中不声明任何 `INTERNET` 权限，不引入任何网络请求与遥测 SDK，杜绝后台流量消耗与隐私外泄。
2. **Android TV Leanback 交互**：
   - 适配电视遥控器 D-Pad 导航，支持卡片聚焦放大与平滑动画。
3. **已安装应用管理与分类**：
   - 自动扫描已安装的电视和通用应用，支持创建自定义应用行与隐藏不需要的系统应用。
4. **双区设置菜单**：
   - **系统原生设置直达**：一键呼出电视系统设置、Wi-Fi、蓝牙外设配对及应用管理。
   - **软件设置**：分类行编辑、儿童防沉迷与全局偏好配置。
5. **儿童模式与防沉迷观看限制**：
   - 支持设置单次（如 30 / 45 / 60 分钟）或每日观看上限。
   - 超时后触发全屏防沉迷遮罩锁屏，屏蔽返回键，需由家长通过遥控器输入正确的 4 位 PIN 码方可延时或解除。

## 🚀 GitHub Actions 自动编译与 APK 下载

本项目已配置 CI/CD 自动化流水线。将本项目推送到您的 GitHub 仓库后：
1. 打开 GitHub 仓库页面，切换到 **Actions** 标签页。
2. `Build OpenTV Launcher APK` 流水线会自动运行并完成编译。
3. 构建成功后，在对应的 Run 详情底部 **Artifacts** 区域即可一键下载已打包好的 `OpenTVLauncher-Release-APK`。
